# ADIA Présence - Manuel utilisateur cabinet

## 1. Objectif du logiciel

ADIA Présence aide le cabinet dentaire à savoir simplement quels patients sont arrivés, quels patients ont validé leur présence, et où en est leur prise en charge.

Le logiciel sert à:

- enregistrer l'arrivée d'un patient;
- prévenir automatiquement l'équipe;
- suivre les statuts des patients;
- coordonner secrétariat, praticiens et assistantes;
- consulter les statistiques d'accueil.

## 2. Rôles utilisateurs

### Secrétariat

Le secrétariat utilise principalement:

- le dashboard;
- la création d'arrivée manuelle;
- les notes internes;
- les statistiques simples.

### Praticien

Le praticien utilise principalement:

- son espace praticien;
- sa file d'attente;
- les actions "Prendre en charge" et "Terminer";
- les notes utiles transmises par l'équipe.

### Assistante

L'assistante utilise principalement:

- l'espace assistante;
- les patients à préparer;
- les salles;
- les informations de coordination.

### Administrateur cabinet

L'administrateur configure:

- les utilisateurs;
- les praticiens;
- les salles;
- les appareils;
- les paramètres du cabinet.

## 3. Utiliser le dashboard

Le dashboard est le centre de contrôle du cabinet.

Il affiche les patients par statut:

- Présence validée;
- En soin;
- Terminés.

### Prendre en charge un patient

1. Repérer le patient.
2. Cliquer sur "Prendre en charge".
3. Le patient passe en statut "En soin".

### Terminer une prise en charge

1. Repérer le patient dans "En soin" ou dans une autre colonne active.
2. Cliquer sur "Terminer".
3. Le patient passe dans la colonne "Terminés".

### Ajouter une note interne

1. Cliquer sur "Note" sur la ligne du patient.
2. Saisir une note courte et professionnelle.
3. Valider.

Les notes internes ne doivent pas contenir de diagnostic ou d'information médicale détaillée.

## 4. Utiliser l'espace praticien

L'espace praticien affiche:

- le prochain patient;
- la file d'attente;
- les actions principales.

Actions disponibles:

- Pris en charge;
- Terminer;

Le praticien doit maintenir les statuts à jour pour que le secrétariat ait une vision fiable.

## 5. Utiliser l'espace assistante

L'espace assistante affiche les patients à préparer et les salles associées.

L'assistante peut:

- voir le patient concerné;
- voir la salle;
- signaler qu'une préparation est prête.

## 6. Utiliser l'écran salle d'attente

L'écran salle d'attente affiche uniquement les informations nécessaires pour appeler un patient.

Exemples:

- "Camille R.";
- "Patient 12";
- "Veuillez vous présenter en salle 2".

Le cabinet peut choisir un mode d'affichage confidentiel pour éviter d'exposer les noms complets.

## 7. Consulter les statistiques

La page statistiques permet de consulter:

- nombre de patients;
- visiteurs;
- attente moyenne;
- prise en charge moyenne;
- retards;
- absences.

Un export CSV est disponible pour analyse ou archivage.

## 8. Bonnes pratiques d'utilisation

- Garder les statuts à jour.
- Ne pas laisser un patient en "Arrivé" s'il est déjà en soin.
- Utiliser les notes internes seulement pour des informations utiles à l'accueil ou à l'organisation.
- Ne pas saisir d'informations médicales sensibles dans les notes internes.
- Vérifier l'écran salle d'attente en début de journée.
- Vérifier que la tablette est bien sur l'écran d'accueil.

## 9. En cas de problème

Si la tablette ne répond pas:

1. vérifier la connexion réseau;
2. revenir à l'accueil;
3. prévenir le secrétariat;
4. utiliser une arrivée manuelle si nécessaire.

Si l'appel ne s'affiche pas en salle d'attente:

1. vérifier que l'écran est allumé;
2. vérifier que la page salle d'attente est ouverte;
3. réessayer l'appel depuis le dashboard.

Si une erreur d'identité apparaît:

1. ne pas insister devant le patient;
2. demander une vérification au secrétariat;
3. corriger l'information depuis l'administration si nécessaire.
